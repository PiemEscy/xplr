Create a reusable GuestLayout architecture inside components/layout for a Next.js App Router project using TypeScript and Tailwind CSS.

Goal:
Build a lightweight, reusable layout for public-facing pages such as:
- Homepage (app\page.tsx)
- Login (app\(auth)\login\page.tsx)
- Register (app\(auth)\register\page.tsx)
- Forgot Password (app\(auth)\forgot-password\page.tsx)
- Any unauthenticated pages

This layout should be separate from the AppLayout  and must not include sidebar navigation.

Requirements:
- Use Next.js App Router structure
- Use reusable components
- Clean separation from AppLayout system
- Production-ready and scalable
- Minimal but modern design

Layout Structure:
- Simple top navbar (optional logo + links only)
- Centered content area
- Full height responsive layout
- Footer (optional)
- No sidebar
- No admin navigation

Navbar Requirements:
- Left: Logo or brand name
- Right: Optional links (Login, Register)
- Minimal and clean
- Sticky optional

Page Container:
- Center content horizontally and vertically when needed (e.g. login page)
- Allow full-width layout for homepage
- Responsive padding system
- Max width container support (e.g. max-w-6xl, max-w-md for auth pages)

Design Style:
- Modern SaaS minimalist style
- Similar to Notion, Vercel, and Stripe landing pages
- Clean whitespace
- Soft background
- Subtle gradients allowed but not heavy
- Rounded cards (xl/2xl)
- Light shadowing

UX Requirements:
- Fully responsive
- Mobile-first design
- Smooth transitions
- Proper spacing and typography hierarchy
- Accessible layout

Architecture Requirements:
- Separate from AppLayout (no shared sidebar logic)
- Reusable layout wrapper: GuestLayout
- Shared UI components (Button, Input, Card)
- Clean folder structure under components/layout/guest
- Avoid monolithic files

Suggested Structure:
- components/layout/guest/
  - GuestLayout.tsx
  - GuestNavbar.tsx
  - GuestContainer.tsx
- components/ui/
- config/

Usage Examples:
- Wrap homepage with GuestLayout (full width mode)
- Wrap login/register pages with centered mode

Behavior Requirements:
- Support two modes:
  1. fullWidth layout (for landing page)
  2. centered layout (for auth pages)

Technical Requirements:
- Use Tailwind CSS only
- Use shadcn/ui components where appropriate
- Use React Server Components where possible
- Keep components reusable and composable
- Avoid duplication with AppLayout

Output:
- Folder structure
- GuestLayout implementation
- Navbar + container components
- Example usage in pages (home + login)
- Clean scalable architecture
